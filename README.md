# gyubee

학자금 등 복리후생 신청의 증빙을 검수하는 프로젝트입니다. 현재 저장소에는 팀 개발을 시작하기 위한 브랜치와 협업 템플릿이 있습니다.

| 브랜치 | 용도 |
|---|---|
| `main` | 통합 검증을 마친 발표 및 배포 버전 |
| `dev` | 네 팀의 코드로 가상 신청 한 건을 검증하는 통합 브랜치 |
| `team/ocr` | 문서 판독과 표 복원 및 개인정보 마스킹 |
| `team/jev` | 규정 질문과 Jev 판정 |
| `team/frontend` | 신청자와 HR 및 규정 관리자 화면 |
| `team/backend` | 신청 접수와 규정 버전 및 결과 저장 |

[협업 규칙](CONTRIBUTING.md)에 따라 해당 팀 브랜치에서 이슈별 작업을 시작합니다.
